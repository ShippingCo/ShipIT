# Booking modal preview

Mode: Operate. Code-led extension of ShippingCo's established white, gray and restrained blue UI. User approved the exact concept in chat: centred modal, From, To, Parcel and Billing, Review and print. No new product interview or concept selection needed; this is an isolated interactive demonstration, not a change to the production application.

Audience: Indian SME courier counter staff, simple English. Customer name search with inline creation, one receiver, multiple parcels, packed kg separate from liquid volume, service setup within same modal, automatic internal references, optional attachments, review and print. Countries and payment options represent only demonstrated capabilities. Sample prices and GST arithmetic are illustrative, not live rates or a compliance claim. Files stay on the device. No dependencies, network calls, or persistence.

First viewport: compact modal title and steps, prominent customer lookup, useful sample matches and Add customer; fixed action footer. Completed steps editable. Native dialog keeps keyboard focus inside, Escape offers retain/discard when changed. Mobile becomes full-screen. Service setup temporarily replaces body and returns to preserved booking.

Visual contract: Segoe UI system text 14px, headings 19/22px, neutral gray text, #2868c7 primary, #f0f0f0 sidebar; flat sections and light rules, 40px minimum controls, visible focus, responsive two-column forms. No image generation; icons are small consistent stroke SVGs.

Write boundary: previews/booking-modal and ignored dist verification artifacts only. No application edits or commits.
